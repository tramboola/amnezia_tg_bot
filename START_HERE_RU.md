## Что уже работает

Проект развёрнут на VPS `108.174.78.189`, Ubuntu 24.04, в `/opt/amnezia-tg-bot`.
Endpoint VPN: `108.174.78.189:51820/UDP`.
Бот управляет одним сервером AmneziaWG 3.1: создаёт отдельные конфиги устройств,
повторно выдаёт их, отзывает доступ и показывает статус. Доступ к боту разрешается
по числовым Telegram ID администраторов в личном чате.

По последней проверке бот работает, менеджер healthy, VPN запущен, неприменённых
изменений нет. Создание настоящего конфига подтверждено пользователем. Интернет,
DNS и отзыв доступа проверены двумя временными Linux-клиентами. Они подключались
к серверу через Docker bridge. Наблюдался и внешний handshake, но импорт конфига,
интернет и поведение IPv6 на устройстве коллеги ещё нужно подтвердить.

## Проверка на действующем VPS

Первичная установка уже выполнена. Для просмотра состояния:

```bash
cd /opt/amnezia-tg-bot
sudo docker compose ps
```

В Telegram используйте `/status`. Для проверки клиентского подключения скачайте
`.conf` из бота и импортируйте в свежий клиент с поддержкой AmneziaWG 3.1:
https://docs.amnezia.org/ru/documentation/instructions/use-amneziawg-app/

После включения VPN должны открываться сайты, работать DNS, а проверка IPv4
на https://api.ipify.org должна показать `108.174.78.189`. На устройстве с IPv6
отдельно проверьте, что он не уходит напрямую через провайдера. Для каждого
устройства создавайте свой конфиг. Действующие профили коллег уже выдаются;
проверки с отзывом доступа или удалением сервера проводите на тестовых профилях
с заранее понятным владельцем.

## Установка на другом VPS

Распакуйте архив, перейдите в `amnezia_tg_bot` и следуйте разделу установки README.
Первичный запуск на Ubuntu:

```bash
sudo bash install.sh
```

Установщик собирает Docker-образы, запрашивает токен скрытым вводом и числовые
Telegram ID администраторов. На другом VPS укажите его собственный публичный IPv4
и откройте выбранный UDP-порт. Сборка требует доступа к сетевым репозиториям.
Один экземпляр бота должен получать обновления одного Telegram-токена; для
отдельной тестовой установки создайте отдельного бота.

## Состав архива

- `src/amnezia_bot/`: бот, менеджер, RPC и управление VPN.
- `vpn/`, `Dockerfile`, `compose.yaml`, `install.sh`: сборка и запуск.
- `pyproject.toml`, `tests/`: зависимости и тесты.
- `README.md`, `LICENSE`, `AGENTS.md`, `.docs/`: инструкция и проектные записи.
- `.env.example`: шаблон с примером ID, не рабочие настройки.
- `CONTENTS_SHA256.txt`: контрольные суммы файлов внутри архива.

В архиве нет токена бота, SSH-ключей, выданных VPN-конфигов, рабочего состояния
сервера, Docker-томов и резервных копий. Это пакет исходников, не копия действующих
доступов. Получать креды заново для просмотра и разработки кода не требуется.

При обслуживании сохраняйте серверные тома: `docker compose down -v` удаляет
ключи и состояние. Обновление и резервное копирование описаны в README.
